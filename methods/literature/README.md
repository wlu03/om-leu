# Literature surveys

- `swissmetro_survey.md` — choice, hybrid and ML / DL / LLM models estimated on Swissmetro.
- `optima_hybrid_choice_survey.md` — Optima papers and the hybrid choice / ICLV methodology they illustrate.
- `lpmc_survey.md` — London Passenger Mode Choice papers (GBDT, RUMBoost family, robit, KLR, GNN, FM adapters).
- `llm_choice_survey.md` — LLMs as predictors, feature / latent-variable generators, synthetic respondents and modelling assistants.

Surveys were compiled on 2026-09-05 from arXiv, publisher records and the
EPFL TRANSP-OR technical reports; items marked "unverified" could not be
checked against the full text.
